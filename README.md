# 🚗 ShiftAuto — Premium Automotive Marketplace

[![React](https://img.shields.io/badge/React-18.x-61DAFB?style=flat&logo=react)](https://reactjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.x-38B2AC?style=flat&logo=tailwind-css)](https://tailwindcss.com/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**ShiftAuto** is a modern, responsive single-page web application designed for browsing, buying, and selling premium high-performance vehicles. Built with React and styled with Tailwind CSS, it features a sleek dark mode UI tailored for luxury automotive enthusiasts.

---

## ✨ Features

- 🏎️ **Dynamic Vehicle Catalog:** Browse high-end cars with high-resolution image galleries and specs.
- 🔍 **Advanced Filtering:** Filter vehicles by brand, category, price range, mileage, and condition (new/used).
- 📸 **Interactive Listing Wizard:** Step-by-step vehicle publishing flow with custom image uploads and real-time previews.
- 💬 **In-App Messaging:** Real-time chat interface to send offers and communicate directly with sellers.
- ❤️ **Favorites System:** Save and manage your favorite listings seamlessly.
- 👤 **Custom User Profile:** Personalized dashboard showing active listings and account details.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Hooks, Functional Components)
- **Styling:** Tailwind CSS (Dark Mode Design, Custom Glassmorphism)
- **Icons:** Lucide React
- **Build Tool / Single File:** HTML5 + Embedded React (CDN / Bundle)
